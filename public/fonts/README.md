# Fonts

Self-hosted so the dashboard paints without a network font service (offline and
air-gapped installs included). Latin and Latin Extended subsets, as served by
Google Fonts:

- Geist, Geist Mono (variable, 100-900): Vercel, SIL Open Font License 1.1
- Newsreader 700 italic (the wordmark): Production Type, SIL Open Font License 1.1
